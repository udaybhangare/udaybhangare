### featured: [routegraph](https://github.com/udaybhangare/routegraph)

<div align="center">

[![npm](https://img.shields.io/npm/v/%40routegraph%2Fcore?style=flat-square&color=6366f1&label=npm)](https://npmjs.com/package/@routegraph/core)
[![License: MIT](https://img.shields.io/badge/license-MIT-6366f1?style=flat-square)](https://github.com/udaybhangare/routegraph/blob/main/LICENSE)
![Stars](https://img.shields.io/github/stars/udaybhangare/routegraph?style=flat-square&color=6366f1)
![TypeScript strict](https://img.shields.io/badge/any_types-zero-6366f1?style=flat-square)

</div>

File-based routing for REST APIs — your folder structure *is* the API, and no, you don't get to argue with it.

- **One `routes/` folder, five frameworks.** Express, Hono, Fastify, Elysia, Koa — same routes, zero rewrites. Swap the adapter, not your life.
- **10 published npm packages**, all `1.0.0`, all ESM, all built on the same strict TypeScript config so nothing sneaks an `any` past code review.
- **Validation, docs, and a typed client — for free.** Drop in a Zod schema and get request validation, an auto-generated interactive docs UI, and a fully typed API client. No YAML. No codegen ceremony. No "please update the Postman collection."
- **Zero runtime overhead.** Routes are scanned and loaded once at startup — no proxy, no reflection, no magic tax at request time. I checked. Twice.

Live demo: [routegraph.vercel.app](https://routegraph.vercel.app) — go on, try to break it.
